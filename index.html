Connect to Google Sheets
This app syncs all loan data to a shared Google Sheet so both investors can see and update records in real time.
1
Create a Google Sheet — go to sheets.new, create a blank spreadsheet, and copy its Sheet ID from the URL:
docs.google.com/spreadsheets/d/[SHEET-ID]/edit
2
Get a Google API Key — go to Google Cloud Console → APIs & Credentials, create a project, enable the Google Sheets API, then create an API Key. Restrict it to the Sheets API for safety.
3
Make the sheet editable — click Share on your Google Sheet, set access to "Anyone with the link can edit". Share this HTML file with your partner — they enter the same Sheet ID and API Key.
4
Enter investor names — set the names for both investors. These are shared across the sheet.
Your API key is stored only in your browser's local storage and never sent anywhere except Google's servers.
